## Selected Engineering

### [Reliable Webhook Platform](https://github.com/mubidotjs/reliable-webhook-platform)

A webhook delivery platform built around durable acceptance, at-least-once delivery, and recovery from failed background work. It combines a transactional outbox, idempotent event ingestion, bounded retries, HMAC signing, and tenant isolation with an operations UI for immutable attempt history and replay. Failure-path tests, a reproducible local load harness, and documented trade-offs make the behavior inspectable.

**TypeScript · Next.js · PostgreSQL · QStash**
